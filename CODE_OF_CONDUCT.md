# Code of Conduct

## Our standard

We are committed to a respectful, welcoming, and harassment-free project.
Contributors should be considerate, assume good intent while addressing impact,
give actionable feedback, and respect differing backgrounds and experience.

Unacceptable behavior includes harassment, discrimination, threats, deliberate
intimidation, sexualized attention, sustained disruption, and publishing
another person's private information without permission.

## Enforcement

Project maintainers may remove, edit, or reject contributions and may restrict
participation when behavior violates this standard. Reports should be sent
privately to the maintainers through GitHub's private security reporting
feature. Maintainers will protect reporter privacy as far as practical and
respond proportionately and consistently.

This code applies in project spaces and when representing the project elsewhere.

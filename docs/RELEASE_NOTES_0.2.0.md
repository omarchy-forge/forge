# Omarchy Forge 0.2.0 release notes

Omarchy Forge `v0.2.0` adds trusted local visual-development tooling while
preserving Forge's static-check and live-shell safety boundaries.

## Included

- `omaforge dev <directory> --trust-plugin-code` for a one-shot run through the
  project-owned isolated Quickshell harness.
- Fictional in-memory `ready`, `empty`, and `error` state simulation with
  `omaforge dev --state`.
- `omaforge screenshot` for deterministic transparent PNGs rendered from an
  explicit plugin-owned Qt Quick item, never from the desktop or monitor.
- `omaforge dev --watch` for content-based change detection and fresh isolated
  reruns, including recovery after a failed development run and clean Ctrl-C
  cancellation.
- Updated bar-widget scaffolds, tests, documentation, security model, and
  architecture decisions for the new development workflow.

## Security and privacy

Every runtime command requires the literal `--trust-plugin-code`
acknowledgement because QML and documented local commands execute with the
user's authority. Runs use temporary HOME and XDG paths, read-only links to the
installed Omarchy QML contract, a dedicated process group, and a timeout. They
do not install or enable the plugin, modify shell configuration, connect to the
live Omarchy Shell, or add network access.

Screenshot capture uses Qt Quick item rendering through an explicit
`forgeScreenshotTarget`. It cannot fall back to compositor or desktop capture
and refuses to overwrite an existing file.

## Existing projects

Projects generated by Forge `v0.1.0` retain their original one-shot runtime
harness and may use basic watch reruns. State simulation and screenshot capture
require adopting the current generated `tests/runtime`,
`tests/runtime-shell.qml`, demo-state contract, and explicit screenshot target
after reviewing the diff. Forge does not overwrite or migrate project source
automatically.

## Compatibility

This release continues to target the inspected Omarchy 4 manifest schema and
was runtime-verified against installed package `omarchy 4.0.0-1` and
Quickshell 0.3.0. A fresh scaffold passed all three isolated states and
plugin-only screenshot capture. The state contract was also exercised against
a disposable Handoff working-tree copy without modifying the private
repository or live shell.

The documentation website remains undeployed. This release does not connect
`omarchyforge.com`, submit to a marketplace, change Handoff visibility, or
constitute a public launch announcement.

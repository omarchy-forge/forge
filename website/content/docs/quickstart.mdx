---
title: Quickstart
description: Install or build Forge, scaffold a plugin, and run both Forge and official validation.
---

Forge `v0.1.0` is available as a public GitHub release.

## Prerequisites

- Omarchy 4 with shell plugin support.
- Go 1.23 or newer.
- Git for local plugin installation and development.

## Download the release

```bash
mkdir -p omaforge-v0.1.0
cd omaforge-v0.1.0
gh release download v0.1.0 --repo omarchy-forge/forge
sha256sum --check checksums.txt
tar -xzf omaforge_0.1.0_linux_amd64.tar.gz
./omaforge version
```

Use `linux_arm64` instead on an ARM64 machine. Keep the binary in a user-owned
location; Forge does not require `sudo` or install packages automatically.

## Or build from source

```bash
git clone https://github.com/omarchy-forge/forge.git
cd forge
go build -o ./tmp/omaforge ./cmd/omaforge
./tmp/omaforge version
```

## Scaffold a bar widget

```bash
./tmp/omaforge init project-pulse \
  --id dev.example.project-pulse \
  --author "Example Developer" \
  --git
```

Forge refuses dangerous targets, symlinked output trees, and nonempty
directories unless generated-file collisions are explicitly previewed with
`--force`. A freshly created or cloned directory containing only `.git` is
accepted without `--force`, and its Git metadata is preserved. Use `--dry-run`
to inspect the complete write plan.

## Check and validate

```bash
./tmp/omaforge check project-pulse
./tmp/omaforge doctor project-pulse
omarchy plugin validate project-pulse
```

`check` is deterministic and never executes plugin QML. `doctor` adds read-only
local environment probes and invokes the installed official validator.

After reviewing the generated QML and local commands, run its isolated runtime
check without installing it into the live shell:

```bash
./tmp/omaforge dev project-pulse --trust-plugin-code
```

## Try the plugin

Review the generated source before enabling it; plugins run unsandboxed inside
the long-lived Omarchy Shell process.

```bash
cd project-pulse
omarchy plugin add "$PWD" --enable
./demo/run empty
omarchy plugin remove dev.example.project-pulse
```

## Implemented

1. Private repository foundation and upstream contract notes.
2. Bar-widget scaffolder with deterministic golden tests.
3. Shared check engine, machine reports, and local doctor.
4. Checksum-verifying GitHub Action and release pipeline infrastructure.
5. Documentation website source with complete initial navigation.
6. Private Handoff reference-plugin MVP with reviewed local persistence and
   Omarchy 4 live verification.

## Handoff status

Handoff can pin a Git project, save one next-step note, show branch and commit
context, and open the project in a terminal. It lives in a separate private
repository. Its private `v0.1.0` source release passed an exact-tag Omarchy
installation and cleanup check. It remains unannounced, absent from
marketplaces, and not installed for ongoing use.

## Later

- A service-plus-widget template only after Omarchy documents a stable
  third-party service-access contract or a second independent plugin proves a
  reusable shape.
- Any Handoff marketplace submission, public announcement, visibility change,
  or ongoing local installation, each only with separate explicit approval.
- Website deployment and connection of `omarchyforge.com`, only with explicit
  approval.
- Additional templates only after the first template is proven.
- Trusted local preview, demo, and screenshot tooling.
- Compatibility matrices and editor integration after real demand.

Accounts, authentication, databases, hosted plugin execution, telemetry, and a
cloud marketplace are not planned MVP scope.

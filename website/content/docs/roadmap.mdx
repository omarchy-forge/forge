## Implemented

1. Private repository foundation and upstream contract notes.
2. Bar-widget scaffolder with deterministic golden tests.
3. Shared check engine, machine reports, and local doctor.
4. Checksum-verifying GitHub Action and release pipeline infrastructure.

## Current milestone

The documentation website is being built with a homepage, quickstart, template
guide, command and manifest references, compatibility evidence, roadmap, and
contribution guidance. Deployment to `omarchyforge.com` requires separate
explicit approval and is not part of the local website implementation.

## Later

- A separately released Handoff reference plugin.
- Additional templates only after the first template is proven.
- Trusted local preview, demo, and screenshot tooling.
- Compatibility matrices and editor integration after real demand.

Accounts, authentication, databases, hosted plugin execution, telemetry, and a
cloud marketplace are not planned MVP scope.
